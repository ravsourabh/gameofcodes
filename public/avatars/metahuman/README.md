# Optional local avatar imports

The production browser studio uses the bundled Microsoft Rocketbox assets.
MetaHuman catalogue exports and Epic character binaries remain local and are
excluded from this public source repository. A fresh clone reports MetaHuman as
unavailable until a separately licensed, validated local import is supplied.

The conversion/lab code is retained under `scripts/metahuman/`, with the failed
visual acceptance and native Unreal separation described in
`METAHUMAN_INTEGRATION.md`. Do not ship the experimental GLB as a production
avatar or redistribute it as a standalone asset pack.
